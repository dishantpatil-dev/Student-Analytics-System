## 🎯 Overview

Student Analytics System converts student information, attendance and marks into organized records, performance analytics and exportable reports. The repository documents the PHP/MySQL implementation, its local setup, and the reporting workflows available in the application.

It is designed around a simple workflow:

```text
Student / Teacher Data
        ↓
     MySQL
        ↓
Attendance + Marks Processing
        ↓
Dashboards + Charts + Reports
```

## ✨ Features

- 👨‍🎓 Student record management
- 📅 Attendance tracking
- 📝 Subject-wise marks
- 📈 Average, percentage and grade calculations
- 🏆 Top-performer analysis
- 📊 Dashboard charts and statistics
- 📋 Pass/fail reporting
- 🖨️ Printable reports
- 📤 CSV export
- 🔐 Login-based access

## 🚀 Getting Started

1. Clone the repository.
2. Place the project inside your XAMPP `htdocs` directory.
3. Start Apache and MySQL.
4. Create/import the required MySQL database.
5. Configure the database connection in the project.
6. Open the application through your local Apache server.

> Database credentials and local environment settings should never be committed as secrets.
